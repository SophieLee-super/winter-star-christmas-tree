# 冬夜星尘圣诞树 · 3D 互动惊喜

一棵长在冬夜里的 3D 圣诞树：圣诞老人乘着雪橇飞过，把四份礼物洒落在树下，点开每一份，都是一份小惊喜。

## 玩法

- **拖动**画面，旋转 3D 视角
- 等圣诞老人派送完礼物，**点击树下的礼盒**拆开惊喜：
  1. 圣诞来信
  2. 冬日暖心约定兑换券（可点击盖章领取）
  3. 冬夜拍立得相册（可切换三张冬日记忆卡片）
  4. 圣诞幸运签（可抽四支祝福签）
- **点击树顶的星星**，彩灯会换一套颜色
- 右上角按钮可开启 **Jingle Bells 圣诞音乐**（Web Audio 音乐盒音色）

## 技术

- 单文件 HTML，Three.js（CDN）粒子圣诞树 + 礼盒 3D 模型
- Web Audio API 合成的铃儿响叮当旋律与风铃音效
- 无需构建，浏览器直接打开 `index.html` 即可
